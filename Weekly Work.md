## Key Lessons

-   Check VM network modes and IP configuration before troubleshooting
    connectivity.
-   Linux permissions should match the access required by the intended
    users and groups.
-   Write-ups are more useful when they explain the purpose of a step
    and what was learned, not only list commands.
-   Keep screenshots and command outputs authentic; include only
    evidence that was actually captured.
